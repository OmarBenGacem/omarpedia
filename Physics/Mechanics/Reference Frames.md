Everything needs to move in a frame, which is defined as some fixed point (an Origin: $O$), with vectors pointing out from these frame. These Vectors ([[Maths/Vector Algebra/Vector Definitions]]) are normally orthogonal and normal, forming an orthonormal basis. This is a very fancy way of describing somthing like the conventional $xyz$ coordinate system.
