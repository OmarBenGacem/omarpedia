# Functionality
Helm is a package manager for Kubernetes, it allows you to take your application and bundle it into what is called a **chart**, then you can easily install and uninstall the app. Helm is not limited to individual apps, it is a Kubernetes deployment tool for automating creation, packaging, configuration & deployment of app s & configurations to Kubernetes clusters.
