# Kubectl  *get*
`kubectl get` is used to get information about anything. Normally you will need to use on of the filters below
### Arguments

| **Flag** | **Usage**                                            |
| -------- | ---------------------------------------------------- |
| **all**  | Get everything. Services, deployments, pods, etc ... |
### Flags

| **Flag** | **Usage**                                                                                                                                                  |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **-a**   | for "all", denoting that you want to see all containers on the host, including containers that have exited (no `-a` means you only see running containers) |
